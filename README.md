# OIBSIP Data Science — Task 1: Iris Flower Classification

This project classifies Iris flowers into Setosa, Versicolor, and Virginica using their sepal and petal measurements. It follows the Oasis Infobyte Data Science Task 1 checklist.

## Dataset

The Iris dataset is loaded from `sklearn.datasets.load_iris()`. It is built into scikit-learn, so no external CSV or data website is required.

## Requirements covered

The notebook includes dataset loading, shape/dtype/null/duplicate checks, descriptive statistics, class distribution, pairplot, box plots, feature-selection discussion, an 80/20 stratified split, two classifiers, accuracy, precision, recall, F1-score, classification reports, confusion matrices, and best-model selection with justification.

## Run

```bash
pip install -r requirements.txt
python iris_flower_classification.py
```

Open `Iris_Flower_Classification_Task1.ipynb` in VS Code or Jupyter and run all cells.
